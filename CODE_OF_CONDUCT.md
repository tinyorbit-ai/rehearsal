# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its code of
conduct. By participating, you agree to abide by its terms.

The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Reporting

If you experience or witness an issue with someone's behaviour in this project's
spaces — issues, pull requests, discussions, or any TinyOrbit-run community
venue — please report it by email to **conduct@tinyorbit.ai**.

Reports are read by the project maintainers. We will acknowledge receipt within
five business days, treat your report confidentially, and follow the
enforcement guidelines published with the Contributor Covenant:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines>

## Scope

This Code of Conduct applies in all project spaces and also applies when an
individual is officially representing the project in public spaces.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
